# Лабораторная работа № 3 — «Доска публикаций»

Асинхронный JavaScript и REST API: работа с `fetch` и `async/await`, вывод данных через DOM, валидация формы и обработка ошибок на чистом JavaScript без фреймворков.

Серверная часть и база данных не требуются: GET- и POST-запросы отправляются к учебному REST API [JSONPlaceholder](https://jsonplaceholder.typicode.com).

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | Разметка страницы: кнопка «Загрузить публикации», список публикаций, форма «Заголовок» + «Текст», область сообщений |
| `style.css` | Оформление страницы |
| `app.js` | Логика приложения: GET- и POST-запросы, валидация формы, обработка ошибок |
| `README.md` | Описание проекта, инструкция по запуску и публикации |

## Требования

- Современный браузер: Chrome, Firefox или Edge.
- Доступ в интернет — запросы уходят на JSONPlaceholder.
- Для второго способа запуска — установленный Python 3.

## Инструкция по запуску

### Способ 1. Открыть файл напрямую (самый простой)

1. Скачайте или скопируйте файлы `index.html`, `style.css` и `app.js` в одну папку.
2. Дважды щёлкните мышью по файлу `index.html`.
3. Страница откроется в браузере — локальный сервер не нужен.

### Способ 2. Через локальный сервер (рекомендуется)

1. Откройте терминал (PowerShell, cmd или bash) в папке проекта.
2. Запустите локальный HTTP-сервер:

   ```bash
   python -m http.server 8000
   ```

3. В браузере откройте адрес: <http://localhost:8000>
4. Чтобы остановить сервер, нажмите в терминале `Ctrl + C`.

## Как пользоваться

- Нажмите **«Загрузить публикации»** — выполняется GET-запрос к `.../posts?_limit=5`, на странице появляются 5 публикаций (заголовок и текст).
- Заполните поля **«Заголовок»** и **«Текст»** и нажмите **«Создать публикацию»** — выполняется POST-запрос, сервер возвращает ID и заголовок созданной записи, форма очищается.
- Если хотя бы одно поле пустое или состоит только из пробелов, запрос не отправляется и выводится сообщение об ошибке.
- При сбое сети или ошибочном HTTP-статусе выводится понятное сообщение, кнопки снова становятся активными.

## Реализовано

- **GET**: `fetch` + `async/await`, проверка `response.ok`, вывод данных только через `textContent` (без `innerHTML`).
- **POST**: обработчик формы через `addEventListener`, `event.preventDefault()` (страница не перезагружается), проверка полей через `trim()`, отправка JSON `{ title, body, userId: 1 }` с заголовком `Content-Type: application/json`.
- **Состояния интерфейса**: сообщения «Загрузка… / Отправка…», временная блокировка кнопок на время запроса.
- **Обработка ошибок**: `try/catch/finally`, отдельное пояснение для сетевых сбоев (`TypeError`), разблокировка кнопок в `finally`.
